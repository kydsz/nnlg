# 同课评教汇总按 teacher_id + course_name 字符串匹配，学期按 semester_config 区间推算

课程级评教汇总（同课评教汇总）需要界定"同一门课"与"同一学期"，但系统没有课程维表（任务上只有 `course_name` 字符串快照），评教任务表也没有 `semester` 字段。因此课程按 `teacher_id + course_name` 精确匹配（与任务创建去重口径一致），学期按任务 `class_time` 落入 `semester_config` 的 `[start_date, start_date + weeks×7)` 区间推算；汇总为实时聚合查询，不落库冗余字段。接受课程名录入不一致（如"高等数学A"与"高等数学A(1)"）匹配不上的局限——引入课程维表需要全量数据回填并改造建任务/课表链路，相对收益不成比例。

「精确匹配」的精确度沿 MySQL 默认排序规则（utf8mb4，大小写不敏感、尾随空格不敏感），与任务创建去重的 SQL 等值比较同口径——口径锚点是去重而非字节级相等；因此 Go 侧聚合的分组键做同样归一化（小写、去首尾空格）对齐，重音折叠不复制（对中文课程名无实际影响）。
